# MCP integrations — 0.5.0

Read the [completed QA record](QA_0.5.0_COMPLETION.md) for actual checks, local-model observations and limits.

Settings → Integrations adds GitHub, Context7 or a custom server. Saving requires review of the endpoint or command. Servers connect on demand. **Test / reconnect** performs connection and discovery, then closes without invoking tools. The advanced result lists protocol and classified tool names. Disable prevents new use; Remove deletes the configuration. Settings changes are refused while another task/service holds the controller lease.

GitHub uses its official remote endpoint, read-only and lockdown headers, and a local read-tool allowlist. Supply a least-privilege token in the protected credential field. OAuth is not implemented. Authenticated repository/issue/PR/Actions reads and a real Balanced CI investigation passed. Lockdown may refuse outsider content intentionally. Context7 supports anonymous access when upstream permits it and an optional protected Bearer credential. Explicit current-library documentation requests select it; ordinary coding tasks do not. Rate limits or connection failures remain visible and do not grant fallback network authority.

For custom stdio, choose an already installed `.exe`, arguments (one per line), and an existing working directory. Scripts need their explicit interpreter. Configuration never installs software. Optional environment variable names reference the protected credential; do not paste tokens into arguments or configuration text. The program runs with your user permissions and may access local files/network. It is not sandboxed. Custom tool effects are unknown and require Execute/Act permissions plus exact call review.

Remote custom servers require HTTPS on port 443 and no URL credentials, query or fragment. Deliberate development endpoints use literal loopback IPs and the local checkbox. Redirects, proxies and public endpoints resolving to private addresses are refused. Settings supports Bearer authentication and bounded header names referencing the same protected credential. OAuth, refresh and arbitrary server credential/input prompts are unsupported.

The official rmcp 3.6.0 SDK handles modern 2026-07-28 discovery/per-request metadata and legacy initialization compatibility. Supported transports are stdio and Streamable HTTP. Discovery is limited to 128 tools/eight pages. Unsupported oversized, reference-bearing or regex-bearing schemas are withheld. At most eight selected MCP tools and 24 KiB of their schemas reach an inference turn. Results are capped and clearly marked when truncated; request narrower evidence when needed.

Capabilities belong to the task. The controller can grant `request_capability` on a later turn without restarting it, after checking intent, configuration and consent. Custom integrations can be explicitly selected using `@` followed by their configured display name. The compact `mcp_find_tools` index searches already connected eligible tools and selects schemas for the next turn; it cannot connect or call them. Activity shows the selected capability groups. Connecting does not approve any tool call. Arguments may disclose project information: review every outgoing call. External effects are outside project Apply/Undo.

Observations are untrusted data and cannot change authority. Credentials are DPAPI encrypted and never intentionally added to prompts, history, diagnostics or exports. Review handoffs before sharing; redaction cannot identify every possible secret. See [security](../SECURITY.md) and [architecture decision](decisions/007-mcp-capabilities.md).

Troubleshooting: verify the exact installed executable/working directory, enable the integration, replace or clear credentials in Settings, or retry discovery after a server update. Safe connection/authentication/rate-limit errors and withheld tool counts persist after restarting. A connection test can be cancelled. A failed call is not retried automatically because its effects may be ambiguous. Timeout/cancellation closes task connections and supervised local process trees. No persistent connection is promised by a successful Settings test.

Anonymous upstream smoke: `cargo run --locked --manifest-path src-tauri/Cargo.toml --example verify_mcp -- context7`. The example reads no environment credential. Synthetic protocol peers live in `fixtures/mcp/server.cjs`.
